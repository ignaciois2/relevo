# Relevo

Landing page del proyecto **Relevo**, una aplicación móvil para técnicos de terreno de un proveedor de internet regional.

El técnico llega al domicilio sin saber qué falló antes en esa dirección. Relevo le entrega la orden de trabajo, el historial de visitas y el material sugerido en el celular, antes de llegar.

## Contenido

- `index.html` — estructura semántica: cabecera, problema, solución y pie
- `style.css` — variables de color, modelo de caja y Flexbox
- `img/prototipo-relevo.svg` — las tres pantallas del prototipo de Figma

## Ver el sitio

Publicado con GitHub Pages en `https://TU-USUARIO.github.io/relevo/`

## Stack

HTML5, CSS3 y Google Fonts (Barlow Condensed e IBM Plex Sans). Sin frameworks ni dependencias.

## Contexto

Proyecto final del Diplomado UX/UI. Módulo 1: investigación de usuario. Módulo 2: prototipo en Figma. Módulo 3: maquetación y despliegue. Módulo 4: auditoría con IA. Módulo 5: presentación.
